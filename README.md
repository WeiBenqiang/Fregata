# Fregata

> Faster Homomorphic Evaluation of AES and SM4 via TFHE

Fregata is an optimized implementation for homomorphic evaluation of **SM4** and **AES** block ciphers based on the [TFHE](https://eprint.iacr.org/2018/421.pdf) fully homomorphic encryption scheme. It provides three distinct bootstrapping modes to balance performance and functionality.

**Paper**: [Faster Homomorphic Evaluation of AES via TFHE (ASIACRYPT 2023)](https://link.springer.com/chapter/10.1007/978-3-031-49187-0_20)

## Prerequisites

- **C++ Compiler**: GCC 10+ or Clang (C++17 support required for CBSmode, C++11 for others)
- **CMake**: >= 3.10
- **TFHE Library**: Required for GBSmode and FBSmode
  - Install from: [https://github.com/tfhe/tfhe](https://github.com/tfhe/tfhe)
- **AVX2 Support**: Required for SPQLIOS FFT backend

### Installing TFHE

```bash
git clone https://github.com/tfhe/tfhe.git
cd tfhe
mkdir build && cd build
cmake ../src -DCMAKE_BUILD_TYPE=optim
make
```

## Build Instructions

Clone the repository:

```bash
git clone https://github.com/WeiBenqiang/Fregata.git
cd Fregata
```

### GBSmode (Gate Bootstrapping)

Uses gate-level bootstrapping to evaluate SM4 and AES homomorphically.

```bash
cd GBSmode
mkdir build && cd build
cmake ..
make
```

**Targets**: `homoSM4`, `homoAES`

### FBSmode (Functional Bootstrapping)

Leverages functional bootstrapping for SM4 homomorphic evaluation.

```bash
cd FBSmode
mkdir build && cd build
cmake ..
make
```

**Target**: `homosm4_fbs`

### CBSmode (Circuit Bootstrapping)

Based on [TFHEpp](https://github.com/virtualsecureplatform/TFHEpp), supports circuit bootstrapping for both SM4 and AES.

```bash
cd CBSmode
mkdir build && cd build
cmake -DENABLE_TEST=ON ..
make
```

**Targets**: `homosm4`, `homoAES` (under `homoSM4_CB/`)

#### CBSmode Build Options

| Option | Default | Description |
|--------|---------|-------------|
| `USE_RANDEN` | ON | Use Randen as CSPRNG |
| `USE_80BIT_SECURITY` | OFF | Use 80-bit security parameter (faster) |
| `USE_FFTW3` | OFF | Use FFTW3 instead of SPQLIOS |
| `USE_MKL` | OFF | Use Intel MKL for FFT |
| `USE_HEXL` | OFF | Use Intel HEXL |
| `ENABLE_TEST` | OFF | Build tests |
| `ENABLE_BENCHMARK` | OFF | Build benchmarks |

## Bootstrapping Modes Overview

| Mode | Cipher Support | TFHE Backend | Description |
|------|---------------|--------------|-------------|
| **GBSmode** | SM4, AES | TFHE (original) | Gate-level bootstrapping, straightforward bitwise operations |
| **FBSmode** | SM4 | TFHE (original) | Functional bootstrapping, evaluates lookup tables directly |
| **CBSmode** | SM4, AES | TFHEpp | Circuit bootstrapping, supports efficient homomorphic multiplexing |
